  • El firmware envía una muestra de texto aproximadamente cada segundo.
  • Java recibe la muestra, comprueba su formato y actualiza las etiquetas Swing.

Adaptación con cinco resistencias de 2 kΩ

  • ECHO: 2 kΩ en paralelo con 2 kΩ equivalen a 1 kΩ.
  • Con R2 = 2 kΩ a GND, el divisor entrega 5 × 2 / (1 + 2) ≈ 3,33 V.
  • Temperatura: dos resistencias en serie forman un pull-up de 4 kΩ a 3,3 V.
  • Se conservan los 21 cables y el firmware.

Recepción: reconstruir líneas completas

for (byte b : bytes) {
    char c = (char) (b & 0xFF);
    if (c == '\n') {
        String line = partialLine.toString().trim();
        partialLine.setLength(0);
        if (!line.isEmpty()) processLine(line);
    } else if (c != '\r' && partialLine.length() < 512) {
        partialLine.append(c);
    } else if (partialLine.length() >= 512) {
        partialLine.setLength(0);
    }
}

Un evento puede traer media muestra o varias muestras. StringBuilder conserva el fragmento hasta encontrar \n.

Errores de sensores y formato visible

private static String formatValue(double value, String suffix) {
        if (!Double.isFinite(value) || value <= -1000) return "--";
        return String.format(Locale.US, "%.2f%s", value, suffix);
    }
  • Los valores no finitos o menores o iguales a −1000 aparecen como “--”.
  • Las medidas válidas muestran dos decimales con Locale.US.
  • La distancia negativa tiene su propio mensaje: “Sin eco”.
  • appendConsole() limita el historial cuando supera 500 líneas.

Desconexión y liberación de recursos

connectionGeneration++;
try {
    if (simulationSocket != null) simulationSocket.close();
} catch (Exception ignored) { }

  • disconnect() cierra el socket o el puerto serie y retira su listener.
  • Restaura botones y estado “Desconectado”.
  • Al cerrar la ventana se llama disconnect() antes de dispose().
  • connectionGeneration permite ignorar el cierre tardío de un intento TCP anterior.
